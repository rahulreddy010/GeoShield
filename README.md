# GeoShield - GPS Spoofing Detection 
https://geoshield-ypd3.onrender.com/
Prototype to detect spoofed GPS signals and protect space-based navigation. 
## Setup
git clone <repo>
cd BugSquad6-Geoshield

# Backend
cd backend
pip install -r requirements.txt
python app.py

# Frontend
cd frontend
npm install
npm start
